이 글은 `_posts` 폴더에 글을 쓰는 방법을 보여주는 예시입니다. 실제 서비스 시작 전 삭제하거나
자유롭게 덮어써도 됩니다.

## 새 글 쓰는 방법

1. `_posts` 폴더 안에 `YYYY-MM-DD-제목.md` 형식으로 파일을 새로 만듭니다.
2. 맨 위에 아래처럼 front matter(제목/날짜)를 넣습니다.

```
---
layout: default
title: "글 제목"
date: 2026-09-20
---
```

3. 그 아래에 마크다운으로 본문을 씁니다. 사진은 `assets/images/` 폴더에 넣고
   `![설명](/assets/images/파일명.jpg)` 형식으로 불러오면 됩니다.

4. GitHub Desktop에서 커밋 후 Push 하면 몇 분 안에 `/insights/` 페이지에 자동으로 목록이
   추가됩니다.

법령 개정 요약, 처리 사례, 실무 체크리스트 등을 이 형식으로 꾸준히 쌓으면 검색·AI 인용 모두에
도움이 되는 콘텐츠 자산이 됩니다.
